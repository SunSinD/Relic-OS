The DejaVu notice is retained for provenance; the bundled UI TTF files have been
replaced with outlines derived from TempleOS, rather than DejaVu glyphs.
The imported CJK fallback covers characters absent from the original font.

Stock-photo wallpapers, classic Winamp skin images and unlicensed ANSI examples
were excluded. The seven player images now present are newly drawn replacements.
The import does not include retail Half-Life/Diablo/Quake data or emulator ROMs.
The older baseline TOOM data listed above is a separate existing component.
A source import is not a claim that every upstream game port is complete,
playable, or suitable for unrestricted redistribution. Per-file provenance and
exclusions are recorded in `research/upstream/platform-import.json`.
