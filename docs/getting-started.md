# Getting Started

To build and run Relic OS, follow [vmware-workflow.md](vmware-workflow.md):
one command (`tools\relic.ps1 dev`) syncs `src/relic/` into the VM and boots it.

## Good First Tasks

- Add source notes to `research/`.
- Build a source inventory for the upstream code.
- Document one subsystem in plain language.
- Keep `src/`, `tests/`, and `tools/` clean as real code appears.

## Suggested Study Order

1. Boot process.
2. Kernel entry and task model.
3. Memory management.
4. Filesystem layout.
5. HolyC and the shell.
6. Graphics and input.
7. Build and emulator workflow.
