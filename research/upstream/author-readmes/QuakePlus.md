# QuakePlus

A continuation from my [QuakeZealOS](https://github.com/y4my4my4m/QuakeZealOS/) implementation.

QuakePlus aims to be more inlined with recent Quake engine implementations, such as Ironwail.
It's got mod support, it also supports the newest Quake 30th anniversary DLC (Dawn of the machine).


The are still issues to be solved (as you'll see in this demo), but apart for the occasional crash, it's fully playable (even multiplayer, it supports protocol 666). 

You can cross play with other Quake engines on different OS.

https://github.com/user-attachments/assets/e0c2416d-3e18-4870-945e-46dd83ba9c86


A reverse port to TempleOS would be relatively easy to achieve if you look at Zeal OS's conversionscripts and do things backwards and simple comment out network and audio function calls.


A big thanks to https://github.com/andrei-drexler/ironwail 
Although I am not directly using any code from ironwail, seeing how to implement things was of huge support and it saved me a lot of time and headache.
